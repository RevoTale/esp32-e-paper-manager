# Native e-paper candidate

Read the [operator guide](docs/native-candidate.md) before connecting or
changing hardware. The package is unflashed and not physically accepted.
Verify all files against `SHA256SUMS` before using the tools or firmware.

The guide covers Linux/arm64 and macOS/arm64 tools, USB, provisioning and the
manager. Supporting profile/resource/security documents are included alongside
source archives and third-party notices. No credentials belong in this package.

`preview-synthetic-stamp.png` uses a fixed synthetic time; it confirms no device
operation. Keep the known-good hardware checkpoint until manual acceptance.
